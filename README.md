SHORTCIRCUITS

AI-based adaptive BLDC fan monitoring and control prototype.

1. Detects Normal, Blade Imbalance, Bearing Wear, Dust Accumulation, and Voltage Sag.
2. Uses 7 motor features for lightweight ML classification.
3. Automatically adjusts the fan speed based on the detected condition.
4. Includes live-style telemetry, AI confidence, and test cases.

Note: This is a software prototype using synthetic test data for demonstration.
